30 ЗАДАНИЙ ПО НАСЛЕДОВАНИЮ C# — ИНТЕРАКТИВНАЯ ВЕРСИЯ

Главная идея:
Программа НЕ содержит готовых пользовательских значений для заданий.
Пользователь запускает программу, выбирает номер задания, вводит данные,
а программа создаёт объекты, выполняет наследование/полиморфизм и выводит
расчёт или результат логики.

Структура:
Program.cs
Zadanie1.cs ... Zadanie30.cs
CS30Nasledovanie.csproj

Запуск:
dotnet run

Или открыть CS30Nasledovanie.csproj в Visual Studio.

После выполнения задания можно вернуться в главное меню.
